# Singleton 패턴 실습 (Python)

## 1. 실행 환경
- 언어: Python
- 버전: Python 3.14.3

## 2. 파일 구성
- `singleton.py` : Singleton 클래스 구현
- `main.py` : 동일 인스턴스 비교와 상태 공유를 확인하는 실행 코드

## 3. 실행 방법
```
python main.py
```
## 4. 실행 결과
```
=== 1. 동일 인스턴스 비교 ===
s1 is s2 : True
id(s1)   : 3165902767504
id(s2)   : 3165902767504

=== 2. 상태 공유 확인 ===
처음 s1.counter : 0
s1으로 2번 증가 후 s1.counter : 2
s2로 읽은 s2.counter          : 2
```
## 5. 설명
- **인스턴스 보관 위치**: 인스턴스는 Singleton 클래스의 클래스 변수 `_instance`에 보관한다. 이 변수는 객체마다 따로 생기지 않고 클래스에 하나만 있어서, 어디서 접근해도 같은 자리를 가리킨다.
- **새 객체가 만들어지지 않는 이유**: `get_instance()`는 `_instance`가 `None`일 때, 즉 처음 호출될 때만 객체를 만들고 그 뒤에는 이미 보관된 객체를 그대로 돌려주기 때문이다. `Singleton()`으로 직접 만들려고 하면 `__init__`에서 에러가 나도록 막아 두었다.
- **하나의 인스턴스를 공유한다는 근거**: `s1 is s2`가 `True`이고 `id`도 같아서 두 변수가 같은 객체를 가리킨다. 또 `s1`으로 바꾼 `counter` 값 2가 `s2`로 읽을 때도 그대로 나왔다.
